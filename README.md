# TailieuHue — Nền tảng chia sẻ & kinh doanh tài liệu Đại học Kinh tế Huế (HCE)

Trang web chính thức: [https://tailieuhue.vercel.app](https://tailieuhue.vercel.app)

## Công nghệ sử dụng
- **Frontend**: Next.js 16 (App Router), React 19, Tailwind CSS v4, Lucide Icons.
- **Backend & Database**: Supabase PostgreSQL, Row Level Security (RLS).
- **Authentication**: Supabase Auth (Google OAuth).
- **Lưu trữ tài liệu**: Google Drive Cloud.
- **Hosting**: Vercel.
